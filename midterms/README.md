# WAD II Lab Cheat Sheet — Weeks 1–5

A searchable local Vue cheat sheet generated from the uploaded Week 1–5 Web Application Development II slides.

## Included
- HTML + vanilla JavaScript / DOM recap
- Web APIs
- CSS basics, box model, Flexbox and Grid
- Bootstrap grid, utilities and components
- Vue fundamentals, binding and Vue Router
- Vue events, lifecycle, computed, forms and list rendering
- Axios / async requests

## Run it before the lab test

```bash
pnpm install
pnpm dev
```

Then open the localhost URL shown in the terminal.

**Important for an offline lab:** run `pnpm install` before the test while you still have internet access.
Keep the project (including `node_modules`) on the laptop you will use.

## Editing
Each skill has its own file in `src/views/`.
Code snippets are shown through the reusable `src/components/CodeBox.vue` component.
The homepage topic list/search terms are in `src/data/topics.js`.

## Source scope
The content is intentionally limited to the uploaded Week 1–5 slide decks. It does not add Week 6 material.
